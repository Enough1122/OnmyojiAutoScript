# MemOS Cloud OpenClaw Plugin 安装记录

## 任务
安装 https://github.com/MemTensor/MemOS-Cloud-OpenClaw-Plugin

## 执行步骤
1. 通过 `openclaw plugins install @memtensor/memos-cloud-openclaw-plugin@latest` 在线安装
2. 插件自动下载并安装到 `C:\Users\admin\.qclaw\extensions\memos-cloud-openclaw-plugin`
3. 配置文件 `C:\Users\admin\.qclaw\openclaw.json` 自动更新（添加了 plugins 配置）
4. 执行了 Gateway 重启（SIGUSR1 热重载）

## 安装结果
- ✅ 插件安装成功（版本 0.1.15）
- ✅ 配置文件已更新
- ✅ Gateway 已重启

## 待完成：配置 API Key
插件安装完成后需要配置 MemOS API Key 才能正常使用：

1. 访问 https://memos-dashboard.openmem.net/cn/apikeys/ 获取 API Key
2. 将 Key 写入配置文件，有两种方式：

**方式一：写入 .env 文件（推荐）**
```
# C:\Users\admin\.qclaw\.env （注意不是 C:\Users\admin\.openclaw\.env）
MEMOS_API_KEY="mpg-你的key"
```

**方式二：直接写入 openclaw.json**
```json
{
  "plugins": {
    "entries": {
      "memos-cloud-openclaw-plugin": {
        "enabled": true,
        "config": {
          "MEMOS_API_KEY": "mpg-你的key"
        }
      }
    }
  }
}
```

保存后需重启 Gateway：`openclaw gateway restart`

## 插件功能
- **Recall**：每次 agent 启动前从 MemOS Cloud 搜索记忆
- **Add**：每次 agent 结束后将对话保存到 MemOS Cloud
- **本地配置页面**：启动后访问 http://127.0.0.1:38463 编辑配置
