## 三、原因分析

### 1. 深夜加餐吃掉了一周的赤字（主因）

已记录的摄入与 400 大卡预算严重脱节：

- 8/24 晚：凉菜 + 地三鲜 + 锅包肉 ≈ **1500+ 大卡**
- 8/25：午 0 + 晚 ~350 + 凌晨灯影牛肉 208 + 华莱士 850 + 荔枝汁 234 + 肉松面包 278 ≈ **1920 大卡**
- 8/26：午 165 + 晚 570–700 ≈ **800 大卡**
- 8/30：~795 大卡 / 蛋白 54 g
- 9/01：~352 大卡

粗算：2500 大卡 ≈ 1 斤脂肪。一次 1500–2000 大卡的深夜放纵，等于把 **4–5 天的赤字直接清零**。8/24 与 8/25 两晚合计 ~3400 大卡，正好解释了本周为什么从 196.4 反弹到 198.4 且迟迟不落。

**这不是意志力问题，是方案设计问题**：400 大卡/天的预算低于长期可执行水平，必然周期性崩盘。崩一次，全周归零。

### 2. 便秘污染了体重读数

- 8/31、9/1 连续两天记录「未排便·只排尿」
- 8/30 的 196.1 是「15:33 拉后称 + 早午未进食」，属于**半空腹脱水口径**，与 9/1 的 198.4「未排便晨重」不可比
- 8/22 也记录「本周围绕便秘硬是逼出来了」

替尔泊肽延缓胃肠蠕动 + 极低热量低残渣 = 便秘几乎是必然。肠道内容物会带来 1–2 斤的读数差，直接制造「反弹」假象。

### 3. 称重口径混乱

目前混用了：空腹晨重、午间称、傍晚饭前、饭后、凌晨睡前。不同口径混算涨跌会产生大量假信号。8/30 的 196.1 与 8/31 的 197.1 里，真脂肪变化可能不到 0.3 斤。

### 4. 蛋白不足 + 无力量训练 → 肌肉流失

- 蛋白实际 50–80 g/天，99 kg 体重的需求是 **100–120 g/天**
- 档案记载运动方案「未确认采纳」
- 极低热量 + 无抗阻训练 = 持续掉肌肉 → 基础代谢下移 → 后续更难减、反弹更快

### 5. 熬夜是放纵夜的直接触发条件

所有破戒全部发生在 **0:30–3:00** 窗口（8/24 晚、8/25 凌晨 0:57 与 1:00、8/26 凌晨 0:57）。熬夜 → 皮质醇升高 → 夜间食欲失控 + 水潴留。这不是巧合，是机制。

## 四、行动方案（按优先级）

### P0 · 修数据与口径（不修这个，其他都白搭）

1. **只认晨重做趋势**：起床 → 排尿后 → 排便前后在备注里标注「已拉/未拉」。晚重、睡前重只记录，不参与趋势判断。
2. **看 7 日移动平均，不看单日涨跌**。单日 ±2 斤 100% 是水。
3. 每次称重在备注写清口径三要素：**时间 / 是否排便 / 饭前饭后**。

### P0 · 封锁深夜窗口

1. 预算从 400 提到 **800–1000 大卡/天**，但 **22:30 后封嘴**。理由：800–1000 稳定执行的周赤字仍有 ~9000 大卡 ≈ 2.5 斤，比 400 大卡崩两次强得多。
2. 22:00 后用系统屏幕时间锁掉外卖 App。
3. 21:30 刷牙作为「厨房已关闭」的仪式锚点。
4. 22:30 后如果真饿，只给固定低卡选项：黄瓜 / 无糖气泡水 / 无糖龟苓膏 / 少量鸡胸。

### P1 · 通便（直接影响读数与身体感受）

- **镁剂**：氧化镁或柠檬酸镁 300–400 mg，睡前服（先确认肾功能正常）
- **水**：每天 2.5–3 L，晨起空腹 500 ml 温水
- **可溶性纤维**：洋车前子壳 10 g/天 或 奇亚籽 15 g 泡水
- **晨起咖啡**：利用胃结肠反射，固定时间如厕 5–10 分钟

### P1 · 蛋白与力量训练（保肌肉 = 保代谢）

- 蛋白目标提到 **100–120 g/天**（优先：虾、鸡胸、蛋清、豆干、带鱼、青花鱼）
- 每周 3 次，每次 20 分钟居家抗阻：深蹲、跪姿俯卧撑、弹力带划船、平板支撑。不需要健身房，不需要器械。

### P1 · 睡眠

目标 **0:30 前入睡**。这是减重杠杆，不是养生建议——数据显示破戒与熬夜 100% 重叠。

### P2 · 医疗检查（风险提示，非诊断）

4.5 个月 -45.6 斤 + 400 kcal/天 + 替尔泊肽 10 mg/5 天（等效 ~14 mg/周，属 off-label），属于需要医学监护的情形。建议尽快做一次：

- 肝肾功能、电解质（钾/钠/镁）、尿酸、血脂
- 肝胆超声（快速减重 >1.5 kg/周 时胆结石发生率可达 10–25%）
- 如出现右上腹剧痛、持续乏力、心悸、明显脱发，立即就医
