- **≥15g 蛋白/100大卡** ✅ **达标**（蛋白密度高，热量低）

## 💡 速查使用规则

1. **克数 × 大卡/100 = 总大卡**，蛋白同理
2. **鲜品重量 = 下锅前**，不是煮熟后
3. **包装食品**（火腿肠、虾袋装）→ 以包装营养表为准，速查表仅供参考
4. **不确定数据** → 标"⚠️ 待复核"，不凭印象填
5. **每次审计更新一次**（不再"每周更新"僵化节奏），有新食材或采购后立刻补
6. **过线基准 = 鸡蛋清 19.3g/100大卡**（取代旧的"豆干 15g/100大卡"基准）

> 📌 **蛋白密度速算公式**：蛋白密度 = 蛋白g / 大卡 × 100。如 118 大卡 + 24.6g 鸡胸 = 24.6 / 118 × 100 = **20.8g/100大卡**。

## 🍳 烹饪系数（D5）

**速查表所有数值都是"生重 / 下锅前"。煮熟后称重会缩水 10-20%。**

| 烹饪方式 | 蛋白质浓度变化 | 说明 |
|:---|:---|:---|
| 水煮白灼 | 缩 10%（水分流失） | 100g 生 → 90g 熟 |
| 蒸 | 缩 10% | 类似水煮 |
| 炒（少油） | 不缩反而略涨 | 蛋白质含量被浓缩，但油加进去了 |
| 烤/空气炸锅 | 缩 15-20% | 水分蒸发最多 |
| 油炸 | 缩 30% + 脂肪翻倍 | 蛋白质浓度被稀释 |

> ✅ **核算建议**：白灼/蒸按生重 0.9 倍算熟重；空气炸锅按 0.85 倍；油炸必须把油的热量也加进去（不能用表里的"脂肪g"）。

## 🧮 快速计算器（D4）

**Python 一行命令**（跑完粘到日记）:
```python
def meal(items):  # items = [(名称, 克数, 大卡/100g, 蛋白/100g, 脂肪/100g), ...]
    total_kcal = sum(g * k / 100 for _, g, k, _, _ in items)
    total_protein = sum(g * p / 100 for _, g, _, p, _ in items)
    total_fat = sum(g * f / 100 for _, g, _, _, f in items)
    density = total_protein / total_kcal * 100 if total_kcal else 0
    return total_kcal, total_protein, total_fat, density

# 例: 老火腿175g + 鱿鱼150g + 紫菜5g
items = [("老火腿", 175, 119, 18.0, 4.5),
         ("鱿鱼", 150, 92, 17.0, 1.6),
         ("紫菜", 5, 207, 26.7, 1.1)]
kcal, p, f, d = meal(items)
print(f"总: {kcal:.0f}大卡 / {p:.0f}g蛋白 / {f:.0f}g脂肪 / 密度 {d:.1f}")
# 输出: 总: 359大卡 / 59g蛋白 / 10g脂肪 / 密度 16.4
```

**Excel 公式**（任意单元格）:
```
总大卡 =SUMPRODUCT(B2:B10, C2:C10)/100      (B=克数, C=大卡/100g)
总蛋白 =SUMPRODUCT(B2:B10, D2:D10)/100      (D=蛋白/100g)
密度   =(SUMPRODUCT(B2:B10, D2:D10) / SUMPRODUCT(B2:B10, C2:C10)) * 100
```
