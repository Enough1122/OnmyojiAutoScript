`base` is `vendor/model`, and `quote(..., safe='')` escapes the `/` between vendor and slug (verified locally: `urllib.parse.quote("z-ai/glm-5.3-flash", safe='')` → `z-ai%2Fglm-5.3-flash`). I checked both forms against the live public API:

2. **非阻塞 — the in-flight coalescer has no way out if the owning thread dies** — `fetch_openrouter_endpoint_slugs` (same added block). A waiter loops on `event.wait(timeout=timeout + 1.0)` and re-checks the cache; the only exits are "cache hit" or "the event was popped and set by the owner". If the owner never reaches its `finally` (thread torn down, interpreter shutdown, or a socket that outlives the timeout), every subsequent caller for that key spins in the loop forever instead of fetching itself or returning None. Since this runs synchronously inside model validation (CLI `/model`, gateway switches), a bounded fallback — e.g. take ownership after N waits, or `event.wait` on a deadline then proceed anyway — would keep a validation call from hanging. Minor in the same area: `_openrouter_endpoint_slugs_cache` is never pruned, so expired entries stay resident for the process lifetime; harmless in a one-shot CLI, worth a delete-on-expiry if this path ever runs in the long-lived gateway.
