This PR caps replayed tool-call ids at 64 chars with a deterministic hash surrogate so oversized ids (notably legacy `__thought__`-blob ids that brick chats via non-retryable 400s) stop failing, clamping both sides of each call/result pair to the same value so pairing is preserved. The surrogate scheme is well reasoned (prompt-cache stability for short ids, same-surrogate pairing). Two robustness gaps remain.

1. **In-place clamp may mutate live transcript dicts without popping the persist marker** — `agent/message_sanitization.py:114` (`clamp_outbound_tool_call_ids(api_kwargs.get("messages"))`) — non-blocking. `clamp_outbound_tool_call_ids` (message_sanitization.py:489+) rewrites `id`/`call_id`/`tool_call_id` in place and returns a `changed` flag the caller ignores. If `api_kwargs["messages"]` aliases the live transcript dicts rather than wire copies, the DB row keeps the original id while memory holds the surrogate — exactly the live/DB divergence class the `_DB_PERSISTED_MARKER` contract (sibling PR #117121) exists to prevent, and no marker pop happens here. Either clamp copies or pop `_DB_PERSISTED_MARKER` on mutated dicts (and invalidate the flush-scan prefix).
2. **A long composite tail can still exceed 64 chars** — `agent/message_sanitization.py:472` (`clamp_tool_call_id`) — non-blocking. Only the `head` (call half) is capped; the returned `f"{surrogate}{sep}{tail}"` keeps the full tail, so a pathological `fc_`-side longer than ~26 chars still 400s. Cap or hash the tail as well when the composite still exceeds `MAX_TOOL_CALL_ID_LENGTH`.
3. **No test for the composite `call_x|fc_y` form** — `tests/agent/test_message_sanitization_policy.py` — non-blocking. The docstring promises the response-item half is preserved, but both tests use plain ids. Add a case asserting the `|tail` suffix survives clamping and both pair sides agree.

Minor: `clamp_outbound_tool_call_ids` iterates `messages if isinstance(messages, list) else ()`, silently no-oping on a missing/non-list `messages` — acceptable, but returning `False` there is indistinguishable from "nothing needed clamping"; fine as is.
