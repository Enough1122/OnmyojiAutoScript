## 3. A string value for `skipSessionSources` silently does nothing

Any truthy value is iterated, so a hand-edited `"skipSessionSources": "kanban"` (instead of `["kanban"]`) becomes `{"kanban"[0], ...}` = `{"k","a","n","b"}` and never matches the session source — the skip silently no-ops with no warning. Related, `look.pick` is "truthy host value, else root" (`client.py:200-202`), so an empty list in a host block falls through to a root-level list; that's fine, just noting the host block cannot clear a root list.
