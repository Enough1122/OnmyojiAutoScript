   The new guards catch `TypeError` and `ValueError`, but `int(float("inf"))` raises `OverflowError` (and Python's JSON reader accepts non-standard `Infinity` by default). Please reject/handle `OverflowError` and non-finite floats (or use one shared finite-safe coercion helper), and add `inf`/`-inf` regression cases.
