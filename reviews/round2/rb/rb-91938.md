Findings below are hardening/quality, none blocking:

1. hermes_cli/web_server.py:3560-3565 — the saturation path serves the profile's last-known platform set with no staleness signal: entry age and fingerprint drift are both ignored by design, so during a wedged-discovery incident a *removed* platform keeps passing `_status_platform_key_allowed` indefinitely and nothing in the response or logs says the set is stale. Why it matters: operators debugging exactly that incident will trust a dashboard that's quietly frozen. Suggestion: log once per profile when serving past-TTL entries under saturation, or annotate the status payload (`configured_platforms_stale: true`).

2. hermes_cli/web_server.py:3550-3553 — `.env` participates in the immediate-invalidate fingerprint, but `.env` is precisely the file external tooling touches most often (credential refreshers, editors doing atomic-rename swaps bump mtime without semantic change). Every such touch forces full plugin discovery + YAML parse on the next poll — the exact cost this cache exists to avoid — with no rate limit on rebuilds beyond the builder permits. Why it matters: a churning credential writer silently degrades the cache to pass-through. Suggestion: either drop `.env` from the stat set (30s TTL bounds it anyway) or hash its content cheaply before treating mtime as semantic.

3. Structure — ~260 lines of invariant-critical synchronization plus nine module globals now live inside an already-huge HTTP server module, one scope away from route handlers. The docstring is genuinely excellent, but the safest way to keep those invariants is physical isolation. Suggestion: extract to e.g. `gateway/_platform_cache.py` (the tests monkeypatch `web_server.<attr>` today; they'd patch the new module just as easily), leaving a thin wrapper here.

4. tests/test_web_server_status_platform_cache.py — coverage breadth is exemplary, but several assertions lean on wall-clock margins (`elapsed < 2.0` after semaphore drains with 2s acquire timeouts; `join(timeout=30)`). On a heavily loaded CI runner the elapsed-style asserts can flake even when the code is correct.
