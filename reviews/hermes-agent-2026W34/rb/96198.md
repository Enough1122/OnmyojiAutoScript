This PR makes the gateway shutdown diagnostic portable to macOS by (1) replacing the GNU-only `timeout` binary with a small Python supervisor wrapper that kills the diagnostic's process group on deadline, adding a darwin-specific snapshot script, and (2) setting `HERMES_GATEWAY_EXTERNAL_SUPERVISOR=1` in generated launchd plists so the launchd-owned gateway no longer loops on the `XPC_SERVICE_NAME=0` sentinel. The new test assertions are correctly gated to POSIX hosts.

Points:

- (minor) The wrapper still hard-depends on `bash` — `child = subprocess.Popen(["bash", "-c", sys.argv[1]], start_new_session=True)` at gateway/shutdown_forensics.py:278 — and has no guard around that spawn (only `ProcessLookupError` around `os.killpg`). If `bash` isn't on PATH (minimal container, non-bash environment), the wrapper crashes and the diagnostic writes nothing at all. Since this PR removes the last GNU-only binary, it would be a good place to either resolve the shell portably (`bash` on macOS is also 3.2) or wrap the internal `Popen` so a missing shell yields a useful log line instead of a silent empty snapshot.

- (minor) Deadline behavior changed from GNU `timeout` semantics: `timeout` defaults to SIGTERM (SIGKILL only with `-k`), while the wrapper goes straight to `os.killpg(child.pid, signal.SIGKILL)` at gateway/shutdown_forensics.py:283. For a snapshot diagnostic this is acceptable, but a short SIGTERM grace would let a slow-but-alive `ps`/`head` flush its inherited-fd output before the kill; with SIGKILL, anything still buffered is lost.

- (very minor) The deadline is now round-tripped as `str(timeout_seconds)` → `float(sys.argv[2])` at gateway/shutdown_forensics.py:280 (previously `f"{timeout_seconds:.0f}"`). Current callers pass a float default, so low risk, but a non-float-convertible value would now crash the wrapper silently rather than surface as a diagnostic problem.

The plist opt-in (hermes_cli/gateway.py:5051) uses an existing documented env-var mechanism rather than a new user-facing config, which fits the repo convention.
