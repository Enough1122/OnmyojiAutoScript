Per the tests, that helper acquires a turn lease (`retainGatewayForSessionTurn`). If the helper retains a lease for every method rather than only turn-producing ones (prompt.submit), non-turn RPCs routed through this callback would hold the socket open past their ACK or wait on a terminal event that never fires. The helper is pre-existing and shared, so this is likely scoped correctly, but it's worth a confirming note that lease acquisition is method-gated and release is bounded.
